## ponytail

Vendored from [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)
(MIT license), v4.9.0, commit `2ed6c52`. Pushes toward the smallest working
solution — stdlib/native before a new dependency, reuse before new code, YAGNI
on speculative flexibility. See `ponytail/SKILL.md` for the full ladder and
rules; `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`,
and `ponytail-help` are its companion one-shot skills (diff review, whole-repo
audit, tracking deferred shortcuts, benchmark scoreboard, and a command
reference, respectively).

To update: re-pull `skills/*/SKILL.md` from the upstream repo and diff before
overwriting — these are unmodified copies of upstream's own SKILL.md files.
